### ملاحظات وحدود معروفة

- فحص mobile عبر حافظة iframe (media queries داخل الإطار تعمل كما في نافذة حقيقية)؛
  لا أداة محاكاة عرض في البيئة — القياسات كمية (overflow/clip/ارتفاع) لا لقطات.
- إيجابيات كاذبة معروفة: عناصر RTL تُظهر `right = viewport+15px` (شريط تمرير)،
  وقياسات التباين عبر `backgroundColor` لا تحسب التدرّجات — عولج القياسان بالأرقام الخام.
- دعم LTR إنجليزي: خصائص منطقية في القواعد الجديدة؛ لا واجهة إنجليزية كاملة في النطاق.
- `data-theme` يُضبط على `<html>`؛ تغييره اليدوي أثناء الفحص يسابق أحيانًا حقن CSS
  الخاص بـHMR — إعادة القياس بعد الاستقرار تعطي القيم الصحيحة (مذكور للصدق المنهجي).
