### الفجوات مقابل المواصفة
1. **لا توجد رحلة موجّهة**: الصفحة الرئيسية للقسم 9 بطاقات متساوية بلا حالة ولا «الخطوة التالية».
2. **جلسة الحفظ** ليست التسلسل المطلوب (نية ← استماع ← عرض ← وحدات ← تكرار ← إخفاء ← ربط ← تسميع ← تقييم ← موعد).
3. **التقييم الذاتي** رقمي 0-5؛ المطلوب أربع صيغ: متقن / جيد ويحتاج تثبيتًا / ضعيف ويحتاج إعادة / لم أتمكن.
4. **المراجعة**: الفواصل ثابتة، لا تفصل قريبة/متوسطة/بعيدة، لا تعالج التراكم والمتأخر بخطة توزيع واقعية، ولا تراعي الوقت المتاح ولا الأخطاء.
5. **سجل الأخطاء والمتشابهات**: لا يوجد (ملاحظات المستخدم الحرة فقط).
6. **التلاوة والاستماع**: لا وحدة مستقلة؛ لا صوتيات مرخصة (انظر القيود).
7. **وضع التركيز** ومؤشر مراحل الجلسة غير موجودين.
8. **الهوية البصرية**: ألوان `quran.css` لا تتبع لوحة المواصفة بالكامل؛ يوجد `prefers-reduced-motion` فقط في موضع واحد (السطر ~1773).
9. **ربط الأهداف** («المؤمن القوي») بنشاط الحفظ: غير موجود. ربط «حاسب نفسك» بإنجاز ورد القرآن: غير موجود.

### قيود وقرارات (من سياسة المشروع)
- **لا صوتيات قرآنية غير مرخصة**: لا تُضمَّن تلاوات حتى يُعتمد مصدر مرخص (نفس قاعدة الأذان). وحدة الاستماع تُبنى على مكتبة يرفعها المسؤول بمصدر وترخيص موثقين، وتبقى حالتها «بانتظار المصدر» حتى ذلك.
- **المتشابهات**: لا تُولَّد من عندنا. تُعرض فقط من مصدر علمي معتمد يُوثَّق لاحقًا؛ حاليًا قائمة «مواضع أخلط فيها» خاصة بالمستخدم.
- **لا قاعدة بيانات موازية**: التوسعات تُضاف إلى جداول `memorization_*` و`revision_events` وإلى `QuranLearningState`.
- **لا ادعاءات شرعية عددية** عن التكرار؛ الفواصل افتراضات قابلة للتعديل.

## 2. المنهجية المعتمدة
تهيئة واستماع ← حفظ جديد بوحدات صغيرة ← تثبيت قريب (اليوم والغد) ← مراجعة متباعدة بحسب الأداء ← مراجعة تراكمية أسبوعية ← ضبط المتشابهات. الفواصل الافتراضية 0/1/3/7/14/30 يوم وتتكيّف مع الإخفاق والنجاح المتكرر. الإتقان لا يُعطى بضغط زر الإنجاز بل بنجاح مراجعات متعاقبة.

## 3. الهيكل الجديد
صفحة «رحلتي مع القرآن» ببطاقة رئيسية وإجراء واحد بارز، ثم أربع وحدات: المصحف، حفظ القرآن، مراجعة القرآن، التلاوة والاستماع. الحديث والأذكار والورد والسجل تنتقل إلى قسم «المزيد» لتخفيف التشتيت.

## 4. قواعد التوجيه (Guided Journey)
1. لا خطة ← «ابدأ رحلتك مع الحفظ».
2. خطة بلا بداية ← «ابدأ جلسة الحفظ الأولى».
3. مراجعات مستحقة ← «ابدأ مراجعة اليوم» (الأبرز).
4. تراكم مراجعات كبير ← اقتراح توزيع واقعي بلا لوم.
5. غير ذلك مع حفظ قائم ← «أكمل حفظك».
