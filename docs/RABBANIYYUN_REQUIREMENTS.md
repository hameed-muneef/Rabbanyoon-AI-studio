# متطلبات مجالس العلم والتواصي والمدارسة

## الواقع الحالي (مراجعة 2026-10-29)

التطبيق React 19 وTypeScript وVite، واجهته عربية RTL. المصادقة عبر Supabase Auth عند ضبط البيئة، وإلا فهناك وضع تجربة محلي. بيانات الاستخدام الحالية تُحفظ في `localStorage` و`public.user_data.payload` JSON للمستخدم المسجل، مع مزامنة تعتمد آخر كتابة ناجحة. المحتوى المشترك في `platform_curriculum`، والإدارة محمية بفحص `is_admin` وRLS وفق الترحيلات. لا تفترض أن الترحيلات المحلية طُبقت على مشروع Supabase البعيد.

الأقسام الفعلية في `src/App.tsx`: الرئيسية، اليوم، الأسبوع، الشهر، الأهداف، السير إلى الله، المحاسبة، الأوراد، الإعدادات. توجد لوحة إدارة للمنهج، ومصادر كتب، وبنية جداول علائقية إضافية موثقة في `DATABASE.md`، لكنها ليست بعد مصدر واجهة التخطيط. لا توجد في الكود حِلَق تواصٍ أو مجالس علم أو قاعات بث أو مدفوعات. القوالب والمكونات الموجودة وإعدادات RTL قابلة لإعادة الاستخدام. ملفات النشر تدعم Netlify وCloudflare؛ لا يوجد خادم تطبيق مستقل.

**مخاطر الأساس:** بيانات JSON والتزامن بآخر كتابة، تفاوت README التاريخي مع التنفيذ، عدم التثبت من حالة قاعدة البيانات البعيدة، خصوصية يوميات المحاسبة، تكلفة البث، وحقوق/مراجعة المواد العلمية. يجب إبقاء وظائف التخطيط والسير الحالية عاملة عند إضافة الوحدات الجديدة.

## الأدوار وتدفقات الاستخدام

| الدور | التدفق الأساسي |
|---|---|
| زائر | يرى الدورات المنشورة العامة وتفاصيل محدودة، ولا يرى أي حلقة تواصٍ |
| مستخدم مسجل | ينشئ حلقة خاصة، يرسل طلب انضمام برابط، يتابع برنامجه، يسجل في دورة مجانية |
| مؤسس الحلقة | يدير الهدف والأعضاء والدعوات والبرنامج وينقل الملكية أو يغلق الحلقة |
| مسؤول/مساعد الحلقة | وظائف مفوضة صراحةً؛ لا يغير صلاحياته بنفسه |
| عضو الحلقة | يرى محتوى حلقته فقط، يشارك وفق الإعدادات، ويغادر |
| طالب | يرى دوراته ولقاءاته ومواده وواجباته، ويدخل القاعة باستحقاق |
| طالب اعتماد معلم | يقدم بياناته ومؤهلاته وتخصصاته؛ لا ينشر دورة شرعية عامة قبل المراجعة |
| شيخ/معلم معتمد | يستخدم المزايا الشخصية المعتادة والتواصي الخاص، ويملك واجهة إضافية لإنشاء وإدارة دورات ودروس منفردة أو سلسلة دروس ومجموعاته الخاصة، ويدير اللقاءات والطلاب ضمن صلاحياته؛ لا يصبح مشرفًا على المنصة تلقائيًا |
| إدارة | تراجع المعلمين والدورات والبلاغات، دون تصفح حر للحلقات الخاصة |

## القواعد الوظيفية

**التواصي:** جميع الحلقات خاصة بلا خيار عام أو بحث أو دليل. الدعوة العشوائية تعرض تعريفًا محدودًا، ثم طلب عضوية وموافقة مخوّل. يمكن إلغاء الدعوة وتجديدها وتقييد عمرها واستعمالها. البرامج قابلة للتخصيص للصلاة والقرآن والأذكار والكتاب والسيرة والتزكية والأعمال النافعة، وتظهر متابعة يومية/أسبوعية/شهرية. المحاسبة الشخصية لا تنتقل إلى الحلقة. إظهار تقدم الفرد للمجموعة يخضع لاختيار واضح، وتعديل البرنامج لا يمحو سجل الإنجاز.

**فصل الواجهات:** للمستخدم العادي واجهته الشخصية والتواصي الخاص ودوراته المسجل فيها. للشيخ المعتمد الواجهة الشخصية نفسها، مع لوحة إضافية للدورات والدروس والطلاب واللقاءات ومجموعاته الخاصة. إنشاء مجموعة تواصٍ من لوحة الشيخ يستخدم قواعد العضوية والدعوة والخصوصية نفسها؛ لا يفتح مجموعة عامة ولا يكشف محتواها لإدارة المنصة. لوحة إدارة المنصة دور مستقل عن اعتماد الشيخ.

**مجالس العلم:** أنواع منفردة ودورية ودورات وقرآن ومراجعة وأسئلة. الدورة لها وصف وأهداف ومتطلبات ومستوى وتصنيف وجدول ومنطقة زمنية وسعة وطريقة تسجيل وحالة نشر ومواد. الدورات المنشورة العامة قابلة للاستكشاف، والخاصة وفق التسجيل أو الدعوة. الصفحات تعرض المعلم والمقاعد والجدول والسعر عند انطباقه والتنبيه بأن اللقاء مباشر ولا توفر المنصة تسجيلًا. لوحة المعلم والطالب تديران اللقاءات والمواد والواجبات والاختبارات والحضور. اعتماد الهوية والمؤهل العلمي والتزكية ثلاث حالات منفصلة.

**البث:** صوت وفيديو وشاشة ورفع يد وتحكم المعلم بالمشاركين والميكروفون والكاميرا وأسئلة نصية اختيارية. دخول برمز قصير بعد تحقق الخادم من العضوية أو التسجيل. لا تسجيل أو تخزين أو تفريغ في النسخة الأولى. يجب بيان أن منع التسجيل الخارجي غير مضمون. دعم أخطاء الأذونات والشبكة وتفاوت إمكانيات الأجهزة.

**المدارسة والتكامل:** مادة وكتاب مجزأ وجدول قراءة وأسئلة واختبار قصير ولقاء مراجعة، مرتبطة بدورة أو حلقة أو محطة من السير إلى الله. مهام الحلقة تدخل يوم المستخدم وأسبوعه وشهره بمصدر واضح ومنع ازدواج، مع موعد شخصي لا يغير جدول الآخرين. الدورة المدفوعة ليست شرطًا للمسار الأساسي. تظل تفاصيل `حاسب نفسك` خاصة.

**الإدارة والخدمات:** إدارة بلاغات ومخالفات ودورات ومعلمين، مع سجل تدقيق وحدود وصول. الوظائف التربوية والعلم الشرعي الأساسي مجاني. يمكن لاحقًا بيع خدمة دورة أو أدوات إدارة متقدمة؛ لا تُحدد أسعار ولا يُربط دفع حقيقي قبل قرار مستقل بشأن البلد والمزود والسياسات. لا تخزين لبيانات بطاقات.

## الصفحات وحالات الواجهة

مجالس العلم: مدخل، استكشاف، تفاصيل، ملف معلم، تسجيل، دوراتي، جدول، قاعة، لوحة معلم، إنشاء/إدارة دورة ولقاءات وطلاب ومواد وواجبات. التواصي: مدخل خاص، حِلَقي، إنشاء، دعوة وطلب، لوحة الحلقة، أعضاء وصلاحيات، برنامج ومهام ومراجعات واجتماعات. لا توجد صفحة استكشاف حلقات.

كل تدفق يعالج التحميل والفراغ وانقطاع الاتصال ورفض الوصول وانتهاء الدعوة والرفض وامتلاء الحلقة وإلغاء/انتهاء اللقاء ورفض أذونات الميكروفون والكاميرا وعدم دعم مشاركة الشاشة. لا أزرار زخرفية. الواجهة عربية RTL على الهاتف واللوحي وسطح المكتب، بتباين وخط واضح وتنقل لوحة مفاتيح وقارئ شاشة ووضع ليلي.

## حدود النسخة الأولى

**الآن بعد الاعتماد:** التواصي الخاص، البرامج والمتابعة، مجالس العلم المجانية ونظام المعلمين، اللقاء المباشر عبر Google Meet المجاني بلا تسجيل من التطبيق، المدارسة الأساسية، التكامل مع التخطيط والسير، وصلاحيات/اختبارات/إشعارات أساسية. تعطى الأولوية لإعداد الصوت فقط عند ضعف الاتصال. الخدمات ذات الخطط المجانية قد تفرض حدودًا أو توقف الخدمة؛ لا يُدّعى أن إطلاقًا عامًا غير محدود سيبقى بلا تكلفة.

**قرار جديد 2026-10-30:** فتح رابط جلسة التواصي المباشرة يتطلب عضوية الحلقة واستحقاق Premium فعّالًا ناتجًا عن دفع متحقق منه، أو منحًا صريحًا لهذه الميزة من أدمن المنصة. يستطيع الأدمن إضافة مميزات إلى فهرس المنصة ومنح ميزة محددة لعضو أو سحبها؛ إضافة الاسم إلى الفهرس لا تنشئ وظيفة برمجية تلقائيًا. لم يُحدد مزود الدفع أو بلد التشغيل بعد، فلا يُعرض شراء اشتراك ولا يُنشأ استحقاق مدفوع من المتصفح. تبقى بقية ميزات التواصي الأساسية وفق صلاحيات العضوية الحالية.

**قرار تنظيمي لاحق 2026-10-30:** تُستخدم «مجالس العلم» للدراسة المنظمة والكتب والدورات والواجبات والاختبارات وتتبع الموضوع أو الشيخ. ويُستخدم «التواصي الخاص» لمجالس الذكر والتأمل والتواصي الجماعي؛ يمكن للمؤسس تحديد هدف المجلس ومحاور الحديث والأسئلة المقترحة، ولا يُفترض وجود واجب عملي لكل مجلس. تبقى الحلقات خاصة بالدعوة والموافقة، ولا يُنشأ دليل عام لها.

**لاحقًا بعد تحديد مزود الدفع:** التحصيل والاشتراكات والفواتير والاسترجاع، والأدوات المتقدمة للمراكز والمعلمين.

**مستقبل اختياري:** تسجيل واستضافة ومشاهدة الدروس عند الطلب وسياسات الاحتفاظ بها. لا تُنفذ في المرحلة الأولى. الحلقات العامة ليست ضمن النطاق المستقبلي.
