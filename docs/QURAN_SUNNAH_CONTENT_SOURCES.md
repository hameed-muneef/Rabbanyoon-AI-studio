### بنية السجل في JSON الرسمي

```json
{
  "id": 1,
  "jozz": 1,
  "page": 1,
  "sura_no": 1,
  "sura_name_en": "Al-Fātiḥah",
  "sura_name_ar": "الفَاتِحَةِ",
  "line_start": 2,
  "line_end": 2,
  "aya_no": 1,
  "aya_text_unicode": "بِسۡمِ ٱللَّهِ ٱلرَّحۡمَٰنِ ٱلرَّحِيمِ ۝١",
  "aya_text_emlaey": "بسم الله الرحمن الرحيم"
}
```

- `aya_text_unicode`: نص العرض العثماني، ويُحفظ حرفيًا بكل حركاته وعلامات الوقف.
- `aya_text_emlaey`: تمثيل إملائي للبحث فقط، ولا يُعرض بوصفه المصحف.
- علامة نهاية الآية `۝` ورقمها العربي جزء من نص المصدر؛ يبقى في النص المحفوظ،
  وتعرضه الواجهة منفصلًا بصريًا عند الحاجة.
- `sura_name_ar` في المصدر مجرور بالحركات؛ تُستخدم أسماء السور من بيانات تنزيل
  (المعتمدة رسميًا) لعناوين الواجهة مع الحفاظ على رقم السورة وربطها بنص المجمع.

### التحقق من المصدر

تم التحقق قبل التوليد من:

- 6,236 آية.
- 114 سورة متصلة الأرقام 1..114.

- أول آية: الفاتحة 1، وآخر آية: الناس 6.
- تطابق SHA-256 المضغوط مع القيمة المنشورة.

### نص الترخيص المختصر

يُسمح بنسخ النص القرآني وتوزيعه نسخًا حرفيًا مع الإسناد إلى Tanzil Project،
ويُمنع تعديل النص أو تغيير ترتيبه. يُنسب النص في التطبيق وفي هذا الملف.

### الحدود المعتمدة في التحقق

يُستخدم تنزيل **للتحقق المستقل فقط**، وليس مصدر العرض. المقارنة تتم على صورة
تحقق مؤقتة تُزال منها الحركات ورموز الوقف وتُوحَّد فروق الهمزات والألف المقصورة
داخل الذاكرة فقط؛ ولا تُخزَّن هذه الصورة ولا تُعرض. الفروق المتبقية فروق رسم
معروفة بين المصدرين (مثل «تلقائي/تلقائ» و«امرئ/امري»)، ولذلك:

- يُشترط تطابق ≥ 99.5% بعد التوحيد.
- تُسجَّل نسبة التطابق وعدد الفروق في تقرير التوليد.
- أي انخفاض عن الحد أو اختلاف في عدد الآيات/ترتيب السور يوقف الاستيراد.

### البيانات الوصفية المستخدمة

- أسماء السور بالعربية والإنجليزية وعدد الآيات والنوع (مكية/مدنية) وترتيب النزول.
- بدايات الأجزاء (30).
- بدايات الأرباع (240 ربعًا) لاشتقاق الحزب: `ceil(quarter / 4)`.
- بدايات الصفحات (604) للمقارنة مع حقل `page` في مصدر المجمع.
- مواضع السجود.

### القيود الملزمة

- لا كشط للمواقع ولا تنزيل جماعي دون إذن صريح.
- لا استبدال جزئي صامت: إن لم تتوفر المجموعة الكاملة المرخّصة، يبقى القسم
  بحالة «المصدر قيد الاعتماد» مع شرح واضح للمستخدم، ولا تُعرض آحاديث ناقصة.
- لا تُخترع درجات صحة أو شروح. تُعرض فقط بيانات المصدر مع إسنادها.
- أنظمة الترقيم المختلفة ليست متبادلة؛ يُحفظ نظام الترقيم والطبعة لكل حديث.

### البيانات المطلوبة لكل حديث عند الاستيراد

- النص العربي الأصلي.
- الصحابي الراوي.
- اسم المجموعة.
- اسم الكتاب والباب.
- رقم الحديث وفق نظام ترقيم محدد.
- الطبعة والمحرر ونظام الترقيم.
- مرجع المصدر ورابطه.
- شرح علمي اختياري بمصدر مستقل وترخيص واضح.
- بصمة الملف المصدر وتاريخ الاستيراد.

### API مفحوص: Sunnah.com API (v1) — غير معتمد

- Base URL: `https://api.sunnah.com/v1/`
- Auth: `X-API-Key` header (مفتاح يُطلب عبر GitHub issue — لم يُحصل عليه بعد).
- Collections: `GET /collections`, `GET /collections/{collectionName}`.
- Books: `GET /collections/{collectionName}/books`, `GET .../books/{bookNumber}`.
- Chapters: `GET .../books/{bookNumber}/chapters`, `GET .../chapters/{chapterId}`.
- Hadiths: `GET .../books/{bookNumber}/hadiths` (paginated, limit≤100)،
  `GET /collections/{collectionName}/hadiths/{hadithNumber}`، `GET /hadiths` (filters: collection, bookNumber, chapterId, hadithNumber)،
  `GET /hadiths/{urn}`، `GET /hadiths/urns?urns=...`، `GET /hadiths/refs?refs=bukhari:1,...`، `GET /hadiths/random`.
- Fields returned per hadith: `collection`, `bookNumber`, `chapterId`, `hadithNumber`, `hadith[]` (lang, chapterNumber, chapterTitle, urn, body, grades[] {graded_by, grade}).
- Collection metadata: `name`, `hasBooks`, `hasChapters`, `collection[]` (lang, title, shortIntro), `totalHadith`, `totalAvailableHadith`.

**الحالة: مرشح، غير معتمد للاستيراد.** الأسباب:
1. لم يُحصل على مفتاح API أو إذن مكتوب.
2. سياسة Sunnah.com المنشورة تمنع الكشط وإعادة نشر مجموعات كاملة؛ وثائق API
   لا تمنح إذن إعادة توزيع النص الكامل. يلزم إذن مكتوب يغطي التخزين والعرض
   وإعادة التوزيع قبل أي نسخة إلى قاعدة البيانات/التطبيق.
3. إجمالي `totalHadith`/`totalAvailableHadith` قد يختلف (hadith مفقود/محذوف)؛
   يجب التحقق من الاكتمال مقابل طبعة مسماة وبنية الكتب/الأبواب؛ لا يُفترض عدد
   موحد بين المصادر أو أن رقمًا نهائيًا يثبت الاكتمال. راجع تقرير التقييم.
4. `hadithNumber` نص (string) وURN عدد (int)؛ نظام الترقيم (Bukhari/Muslim)
   يجب تحديده كتابيًا (طبعة/محرر) قبل التخزين، ولا يُعامل URN كرقم حديث.
5. الدرجات (grades) تُعرض كما وردت من المصدر مع إسناد `graded_by`؛ لا يُخترع
   أو يُعدَّل أي درجة. إذا كانت grades فارغة، يبقى الحقل فارغًا (لا درجة افتراضية).

**خطة التحقق (عند توفر المفتاح + الإذن):**
1. طلب مفتاح عبر GitHub issue (رابط في التخصيص).
2. تنزيل المجموعة كاملة (صفحات 100/صفحة) لكل Bukhari/Muslim.
3. التحقق: العدد الإجمالي، تسلسل الأرقام، بنية الكتب/الأبواب، وجود النص العربي.
4. حفظ بصمة الملف (SHA-256) ونسخة المصدر وتاريخ الاستيراد.
5. تعبئة الجداول عبر سكربت محمي بمفتاح الخدمة (service_role) فقط، على الخادم.
6. لا استدعاء من الواجهة (لا مفتاح في bundle).
7. إضافة اختبارات: عدد، ترتيب، تكرار، تطابق numbering، بصمة.

**لا يُستورد أي نص حديثي الآن.** القسم يبقى بحالة «المصدر قيد الاعتماد».

### API الدرر السنية — مناسب للبحث الشبكي فقط

- صفحة الخدمة الرسمية: https://dorar.net/api-services/hadith
- المسار: `GET /api/v1/hadith/search`؛ بحث بكلمات، حتى 20 نتيجة في الطلب.
- النتيجة تتضمن النص والراوي والمحدّث والمصدر ورقم الصفحة/الحديث ودرجة الحكم
  ورابط المصدر وروابط الشرح/المتشابه.
- التوكن يصدر بعد طلب ومراجعة يدوية، مع بيان الغرض وإتاحة معاينة التطبيق.
- الشروط تلزم بنسبة النص للدرر السنية وإظهار رابط المصدر، وتمنع تعديل الحكم أو
  عرض المتن دون حكمه المرافق، والسحب الجماعي والتخزين الكامل وإعادة النشر.
  التخزين المؤقت للأداء فقط ولمدة 24–48 ساعة، بمعدل معلن 60 طلبًا/دقيقة.
- **القرار:** قد يصلح لاحقًا لميزة بحث وعرض متصل بالإنترنت بعد الموافقة والالتزام
  بالشروط. لا يصلح لاستيراد الصحيحين كاملين أو التخزين المحلي الدائم أو العمل
  دون اتصال، ولا تُستخدم طلبات البحث لإعادة بناء مجموعة محلية.

التفاصيل وقيود كل مصدر في [تقرير تقييم مصادر الحديث](HADITH_DATA_SOURCE_EVALUATION.md).

### مصادر غير معتمدة للاستيراد

- **AhmedBaset/hadith-json** — أذن صاحب المشروع باستخدام fork الخاص به (`hameed-muneef/hadith-json`، HEAD `70b83d6d21995bb32f8d7271cd75501be5a922a7`) للتقييم والتحضير فقط، وليس للاستيراد. الـcommit وملفات البخاري ومسلم مطابقة لـupstream عند commit نفسه؛ لا يوجد LICENSE، ويذكر README أن البيانات مكشوطة من Sunnah.com. إذن صاحب fork لا يثبت حقوق النصوص المنقولة من المصدر الأصلي؛ يلزم إذن مكتوب من أصحاب الحقوق، وتحديد الطبعة والترقيم والتحقق من الاكتمال قبل الاستيراد.

### مرشح إضافي (قيد التحقق)

- **mhashim6/Open-Hadith-Data** (https://github.com/mhashim6/Open-Hadith-Data) — ترخيص ODbL 1.0 + DBCL 1.0؛ 9 كتب (الصحيحان ضمنها)؛ CSV (مع/بدون تشكيل) + تفصيل. **مرشح** (غير معتمد): needs verification of completeness (Bukhari ~7563، Muslim ~7563)، numbering system، edition/editor، narrator/grading fields، and ODbL share-alike/attribution obligations. لا استيراد حتى تحقق.
- **Bukhari:** 7,008 سجل (IDs 1..7,008، بدون تكرار، بدون فجوات) — **أقل من العدد المعياري (~7,563)**. غير مكتمل.
- **Muslim:** 5,362 سجل (IDs 1..5,362) — **أقل بكثير من المعياري (~7,563)**. غير مكتمل.
- **البنية:** 3 أعمدة فقط: رقم تسلسلي، نص (مع تشكيل)، تفصيل/شرح. لا يوجد: رقم كتاب/باب، راوٍ منفصل، درجة، مصدر/طبعة، نظام ترقيم (الرقم تسلسلي داخل مجموعة، ليس numbering معتمد).
- **الخلاصة:** **لا يفي بمتطلب "الصحيح كامل"** (ناقص + غير منظم + لا grading). لا يُستخدم للاستيراد. يبقى Hadith بحالة «محظور».

### مرشح: faressoft/hadith (npm, MIT)

- **المشروع:** https://github.com/faressoft/hadith (MIT License).
- **المحتوى:** 16 مجموعة (الصحيحان، النسائي، أبو داود، الترمذي، ابن ماجه، مالك، أحمد، رياض الصالحين، مشكاة، الأدب المفرد، بلوغ المرام، 40 نووية، 40ات، شمائل، حصن Muslim) — 50,508 hadith عربي + 50,495 ترجمة.
- **البنية:** SQLite (hadith.db، ~139 MB via Git LFS) مع books/chapters/grades/narrator/metadata. MIT للحزمة.
- **القيود:** provenance غير موثق (النص likely من Sunnah.com)؛ 139 MB SQLite (ثقيل للحزمة). لا تحقق من الاكتمال/الطبعة. **مرشح** (غير معتمد) — needs verification of source, edition, grading provenance, and feasibility (size).

### سؤال المستخدم: رياض الصالحين؟

- **نعم، موجود** (1,896 hadith، 20 book) في Sunnah.com (collection `riyadussalihin`) وفي faressoft/hadith.
- **لا dataset مفتوح/مرخص مستقل** (باستثناء Sunnah.com API أو faressoft packaging). Open-Hadith-Data (ODbL) **لا** يتضمن رياض الصالحين (9 كتب فقط، بدونه).
- **المسار الشرعي:** Sunnah.com API (key + permission) — الأفضل (metadata كامل، grading). أو faressoft (MIT، لكن provenance unclear + 139 MB).
