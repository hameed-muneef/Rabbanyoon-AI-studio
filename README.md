للنشر على Netlify مع Supabase، راجع [NETLIFY_DEPLOY.md](NETLIFY_DEPLOY.md).
للنشر على Cloudflare Pages مع ملفات الكتب الكبيرة، راجع [CLOUDFLARE_DEPLOY.md](CLOUDFLARE_DEPLOY.md).

> تحديث قاعدة البيانات: التطبيق يدعم الآن Supabase Auth والمزامنة السحابية وإدارة المحتوى. بعض وصف النسخة الأولية أدناه تاريخي. راجع [DATABASE.md](DATABASE.md) للمخطط العلائقي الجديد، العلاقات والصلاحيات، نتائج مراجعة المشروع، وخطوات تطبيق الترحيلات. الواجهة الحالية ما زالت تستخدم مستندات JSON؛ الجداول الجديدة أساس للانتقال وليست تحويلًا تلقائيًا للبيانات.

واجهة عربية RTL متجاوبة، قابلة للنقل إلى مشروعك، مع وظائف تفاعلية وحفظ محلي.

## التشغيل على Windows (PowerShell)

1. ثبّت Node.js 20.19+ أو 22+.
2. فك ضغط المشروع وافتح PowerShell داخل مجلد `al-rabbaniyyun-mvp`.
3. شغّل:

```powershell
npm install
npm run dev
```

ثم افتح الرابط المحلي الذي يظهر في الطرفية (عادة `http://localhost:5173`).

للتحقق من نسخة الإنتاج:

```powershell
npm run build
npm run preview
```

## ما يعمل حاليًا

- «شهري مع الله»: اختيار السنة والشهر الميلادي وتحديد يوم اختياري لكل مهمة، مع إمكانية نقلها لشهر آخر. تظهر مهام الشهر الموافقة لليوم مع مهام الأسبوع في تنبيه التخطيط اليومي وتضاف عند حفظ المتابعة أو تحديثها. إذا لم يوجد اليوم عند نقل المهمة (مثل ٣١ إلى فبراير)، تبقى دون يوم حتى تختار موعدًا جديدًا؛ والمهام القديمة محفوظة لتوزيعها على الشهور.

- «أسبوعي مع الله»: اختيار السنة ورقم الأسبوع وفق ISO (الاثنين–الأحد)، وجدولة المهام في أسبوع بعينه مع يوم اختياري. مهام اليوم المحددة في خطة الأسبوع تظهر بتنبيه داخل التخطيط اليومي وتُضاف إلى قائمة متابعة اليوم عند حفظها أو تحديثها. المهام القديمة غير المؤرخة تبقى في قسم مستقل لإسنادها إلى أسبوع. المواعيد تحفظ في البيانات المحلية والمزامنة السحابية الحالية.

- الصفحة الرئيسية العربية المتجاوبة مع 3 أقسام رئيسية.
- «حياتي مع الله»: 4 قوالب مستقلة، قوائم يومية/أسبوعية/شهرية قابلة للإضافة والحذف والتأشير.
- مواقيت الصلاة: إدخال يدوي فقط في هذه النسخة؛ لا توجد مواقيت وهمية.
- «المؤمن القوي»: إنشاء أهداف وربط خطواتها بالخطة بموافقة المستخدم.
- «السير إلى الله»: ثماني وحدات تأسيسية في الغاية والمصير ومعرفة الله والأسماء والصفات والقدر والغيب والملائكة والرسل والكتب، لكل منها سبع محطات ومصادر مرتبطة، مع تقدم متسلسل تجريبي.
- «حاسب نفسك»: مراجعات خاصة تحفظ محليًا في المتصفح.
- «زكِّ نفسك»: اختيار أذكار وأهداف عددية يومية/أسبوعية/شهرية مع عداد وتصحيح.
- تسجيل حالة الصلوات الخمس في متابعة اليوم: في الوقت، متأخرة، عذر معتبر، لم تُؤدَّ؛ وترك التسجيل يعني «غير معروف» ولا يدل على ترك الصلاة.
- تجدد قوائم المهام الدورية تلقائيًا: قائمة «يومي مع الله» تبدأ دون تأشير في كل يوم جديد، والمهام الأسبوعية والشهرية لا تختلط بحالة أسابيع وشهور أخرى، مع بقاء سجلات الأيام السابقة كما هي.
- التاريخ الهجري بجانب الميلادي في الشريط العلوي وفي خطط اليوم والأسبوع والشهر، وفق تقويم أم القرى بحساب محلي دون خدمة خارجية؛ وثبوت الشهر الرؤيتي قد يختلف بين البلدان، لذلك يظهر الهجري دائمًا بجوار الميلادي دون اعتماد منفرد.
- حفظ بيانات LocalStorage، وتصدير JSON، وإعادة ضبط البيانات.

## حدود النسخة الحالية (مهم)

- **ليست جاهزة للإطلاق العام**: لا حسابات، لا PostgreSQL، لا API، لا مزامنة بين الأجهزة، لا نظام إدارة شرعي، ولا حماية بيانات مناسبة للإنتاج.
- `localStorage` ليس تخزينًا مشفرًا؛ لا تدخل أسرارًا أو تفاصيل شديدة الحساسية.
- لا يوجد محرك حقيقي لمواقيت الصلاة ولا تنبيهات ولا PWA Offline مكتمل.
- المحطات التعليمية تجريبية؛ لا ينبغي اعتماد محتوى شرعي دون مراجعة وتوثيق.
- أنشطة الخطة اليومية لا تعني أن عدم التأشير عليها يدل على ترك العبادة.
- الأهداف العددية للذكر المطلق تنظيم شخصي لا فضيلة شرعية مخصوصة للعدد المختار.
- تجدد عدادات الأوراد بحسب الفترة عند تحميل التطبيق، وتتجدد قوائم المهام الدورية الآن وفق مفتاح فترة كل مهمة: القوائم اليومية تبدأ دون تأشير كل يوم، والأسبوعية والشهرية مرتبطة بأسبوعها وشهرها؛ وتبقى التذكيرات التلقائية والتقويم الهجري وظيفتين لاحقتين.

## معمارية النسخة

React + TypeScript + Vite + CSS + lucide-react، دون Backend. اختيار Vite هنا مقصود لتقديم واجهة قابلة للتشغيل سريعًا وبتكلفة استضافة ثابتة منخفضة جدًا. يمكن ترحيلها لاحقًا إلى Next.js أو الإبقاء على SPA مع API منفصل حسب الحاجة.

## الخطوات القادمة

1. تصميم Schema PostgreSQL وAPI والصلاحيات.
2. نظام مراجعة ونشر المحتوى الشرعي.
3. تفعيل الوصول المتدرج من Backend وعدم إظهار الوحدات غير المفتوحة.
4. حساب مواقيت الصلاة وفق طريقة مختارة وموقع المستخدم وإتاحة التعديل.
5. تكرار الجداول حسب الأيام/الأسابيع/الأشهر ودعم الأنشطة ذات المواعيد.
6. تسجيل الحسابات والمزامنة وحماية يوميات المحاسبة.
7. PWA مع IndexedDB ومزامنة Offline واختبارات.
8. مراجعة أمنية وإمكانية الوصول واختبارات الأجهزة.

المتطلبات الشاملة الأصلية في `PRODUCT_SPEC.md`.

## محرر «السير إلى الله»

من القسم اختر «إدارة المحتوى التجريبية». يمكنك إضافة وحدة وترتيب الوحدات، وتحرير النصوص السبعة، وإضافة مصدر أو كتاب أو فيديو بواسطة رابط HTTP/HTTPS، وتحديد المؤلف والمرجع والمستوى وربط المصادر بالمحطات. رفع الكتب كملفات ليس ضمن هذه النسخة.

حفظ التعديلات يعيد الوحدة إلى مسودة ويلغي اعتماد النسخة السابقة ويعيد تقدم الوحدة إلى البداية. دورة المحتوى المحلية: مسودة → مراجعة → اعتماد باسم وملاحظة المراجع → نشر. عرض «المحتوى المنشور» يتوقف عند أول وحدة غير منشورة؛ عرض «معاينة المنهج» يتيح تجربة المسودات بالترتيب. لا يشترط إكمال الاستزادة للانتقال.

المحتوى الأولي مسودات تحريرية مستندة إلى القرآن الكريم وصحيح البخاري وشرح ابن باز لمنهج السلف في الأسماء والصفات، مع مراجع وروابط داخل كل وحدة. ليس منهجًا معتمدًا من مراجع شرعي؛ يلزم التحقق العلمي والتحريري قبل الإطلاق.

الإدارة والنشر والاعتماد محلية وتجريبية، وليست نظام صلاحيات. المحتوى، بما فيه الوحدات المستقبلية، موجود في حزمة الواجهة؛ إخفاؤه المتدرج ليس حماية وصول. يتطلب الإنتاج خادمًا وحسابات وأدوارًا مستقلة للمؤلف والمراجع والناشر، وحفظ إصدارات وسجل تدقيق، وتقديم المحتوى المصرح به فقط من الخادم. تُحفظ بيانات المنهج في نفس التصدير المحلي وتُحذف مع إعادة ضبط التطبيق. أي تعديلات غير محفوظة تضيع عند مغادرة المحرر.

للتحقق من منطق المنهج:

```powershell
node --test tests/curriculum.test.mjs
```

## متن كتاب «تعريف عام بدين الإسلام»

أُدخل متن النسخة النصية من المكتبة الشاملة إلى `src/book-text.json`، وحُفظت الصفحات الـ ١٨٠ للنسخة الإلكترونية مع أرقام صفحات المطبوع (٥–١٩٠) وروابط الأصل. استُبعدت فقرات الهوامش (`hamesh`) وعلامات الإحالة الرقمية داخل المتن. يُعرض النص في قارئ صفحات داخل المحطات المناسبة من الوحدات الثماني، بحسب خريطة الموضوعات في `src/book-topics.ts`. يمكن الانتقال بين صفحات الموضوع أو الرجوع إلى صفحته في الشاملة. تغطي الخريطة جميع الصفحات الـ ١٨٠، وقد تتكرر بعض الصفحات عندما يناسب موضوعها أكثر من محور. فصول البداية والقدر والغيب والملائكة والرسل والكتب مضافة ضمن الرحلة، وقراءة الكتاب استزادة اختيارية.

مصدر النص: https://shamela.ws/book/37562 — علي الطنطاوي، *تعريف عام بدين الإسلام*. هذا نص نسخة الشاملة، وقد يختلف ضبطه وعلامات ترقيمه عن PDF المطبوع؛ يلزم تدقيق تحريري وحقوق نشر قبل أي إطلاق عام. لإعادة استخراج النص وفق بنية الصفحات الحالية يمكن تشغيل `scripts/import-shamela.ps1` بعد السماح بالاتصال بالمصدر.


## فيديوهات «رحلة اليقين»

أضيفت الدروس المرقمة ١–٣٠ من قائمة التشغيل التي قدمها المستخدم بوصفها استزادة اختيارية في محاور البداية، ومعرفة الله، والغيب. عدد روابط الفيديو ٣٤ لأن بعض الدروس منشور في جزأين أو معه ملحق. تحفظ العناوين ومعرّفات الفيديو في `src/playlist-lessons.json`، وتظهر كموارد قابلة للتحرير في إدارة المحتوى التجريبية. لا تعد هذه الروابط اعتمادًا علميًا لمحتوى الفيديوهات؛ يلزم مراجعتها قبل النشر العام.
