# Al-Rabbaniyyun Development Instructions

Before starting any development task:

1. Read `docs/RABBANIYYUN_IMPLEMENTATION_PLAN.md`.
2. Review the actual project state and relevant code.
3. Identify the next approved, incomplete task.
4. Implement it according to its acceptance criteria.
5. Run appropriate tests.
6. Update the task status in the implementation plan.
7. Document changes, blockers, and next steps.

Never mark a task complete without verification.
Never assume a task is complete solely because the plan says so.
Keep the implementation plan synchronized with the codebase.
Preserve existing functionality and project architecture.
